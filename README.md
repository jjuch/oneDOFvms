# oneDOFvms — Gyroscopic virtual mechanical system (1 DOF), journal version

Working repository for the journal paper (target: **Automatica**, regular paper)
that merges and extends

* J. Juchem, M. Loccufier, *Shaping energy exchange with gyroscopic interconnections:
  a geometric approach*, IEEE CCTA 2026, pp. 822–828;
* J. Juchem, J. Qian, B. Gopaluni, C. Neary, *Restoring resonant energy exchange under
  imperfect gyroscopic coupling*, submitted to ECC 2027.

Current working title: **Restoring resonant energy exchange in gyroscopic virtual
mechanical systems under delay and sampling.**

```
paper/      LaTeX source (main.tex, sections/, refs.bib, tables/ generated)
figures/    every figure used in the paper (PDF, generated by code/)
code/       Python package `vms` + scripts that generate all figures/tables + tests
```

## Building the paper

```bash
cd paper
latexmk -pdf main.tex          # or: pdflatex main && bibtex main && pdflatex main && pdflatex main
```

**Template.** Automatica uses `autart.cls` / `autart.bst` (IFAC). They are not
redistributed here. Download them (Automatica *Guide for authors*, or the Overleaf
template "Automatica (IFAC Journal)") and put them in `paper/`. `main.tex` detects
them automatically; without them `autart-compat.tex` emulates the frontmatter and a
two-column layout of similar dimensions so the paper always compiles.

**Draft markers.** `\gap{title}{explanation}` prints a numbered red box and collects all
gaps in a list at the end of the PDF (remove `\def\SHOWGAPS{1}` in `macros.tex` to hide
it). `\todoinline{...}` marks small to-dos. Before submission, macros must be expanded
(Automatica asks authors not to use private macros).

## Reproducing figures and tables

```bash
cd code
pip install -r requirements.txt
python -m tests.check_identities      # algebraic identities used in the paper
python -m tests.check_theorems        # delay / ZOH / absorption / authority results
python scripts/make_all.py            # all figures -> ../figures, table -> ../paper/tables
python scripts/make_all.py --force    # also re-run the closed-loop simulations (~1 min)
```

Each figure has its own script (`code/scripts/fig_*.py`). Simulation results are cached
in `code/results/` (git-ignored).

## Collaboration workflow

* **One sentence per line** in `.tex` files keeps diffs readable. The generated draft is
  wrapped at ~80 columns; convert a paragraph to one-sentence-per-line when you edit it.
* **Branch per topic** (`proof/delay-zoh`, `sec/intro`, …) and open a pull request;
  at least one co-author reviews before merging into `main`.
* Mathematical claims are tracked in `NOTES.md`: every assumption has an ID and every
  open problem is a `\gap{}` in the source *and* an entry in the gap table.
* Numerical claims in the text should be reproducible by a script in `code/`; cite the
  script in a LaTeX comment next to the claim.
* `refs.bib` entries marked `% VERIFY` were entered from memory and must be checked.
* Overleaf users: link the Overleaf project to this GitHub repo (Overleaf → Menu →
  GitHub) and pull/push from there.
